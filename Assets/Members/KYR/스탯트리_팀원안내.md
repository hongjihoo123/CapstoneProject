# 플레이어 스탯 트리 — 구조 / 연결 / 사용법

KYR 담당. 위치: `Assets/Members/KYR/01.Scripts/Stats/`
플레이어에 붙이는 컴포넌트: `PlayerStatsModule`

팀원이 버프·스킬·무기에서 만질 API는 `PlayerAgent.Stats` 하나면 된다.

```csharp
using Members.KYR._01_Scripts.Stats;

player.Stats.Get(PlayerStatId.Damage);
player.Stats.AddModifier(id, modifier);
player.Stats.RemoveModifiers(this);
```

---

## 1. 구조

중간 노드(Survival / Mobility / Combat / Skill)는 값이 없다. 자식에게 버프만 흘린다.
리프만 `Get()` 해서 쓴다.

```
Root
├── Survival
│   ├── MaxHp                 기본 100     체력 상한
│   ├── Defense               기본 0       받는 피해 (1 - 값) 감소, 0~1
│   ├── MaxStamina            기본 100     상한만. 현재 스태미나 게이지 없음
│   ├── StaminaRegen          기본 10      초당 회복 기획값. 아직 소모/회복 로직 없음
│   └── HealReceived          기본 1       받는 힐 배율
├── Mobility
│   ├── WalkSpeed             기본 4.5
│   ├── RunSpeed              기본 7.5
│   ├── CrouchSpeed           기본 2.2
│   ├── JumpHeight            기본 1.2
│   ├── DashSpeed             기본 1       대시 스킬 속도에 곱함
│   ├── DashDuration          기본 1       대시 스킬 시간에 곱함
│   └── AirControl            기본 0.7
├── Combat
│   ├── Damage                기본 1       무기 데미지 × 이 값
│   ├── AttackSpeed           기본 1       연사 배율
│   ├── ReloadSpeed           기본 1       재장전 배율
│   ├── RecoilControl         기본 0       반동 (1 - 값) 감소, 0~1
│   └── WeakpointMultiplier   기본 1       약점일 때 Damage에 한 번 더 곱함
└── Skill
    └── SkillCooldownReduction 기본 0      스킬 쿨 (1 - 값) 감소, 0~1. Flat로 넣을 것
```

최종값:

`(기본값 + 자신·조상의 Flat 합) × (1 + 자신·조상의 PercentAdd 합)`

예: `Mobility`에 PercentAdd `+0.1` → Walk/Run/Crouch/Jump/Dash/Air 전부 10% 증가.
`WalkSpeed`만 올리면 걷기만 변한다.

현재 HP는 스탯이 아니다. `PlayerHealth`의 `_hp`다.
MaxHp가 줄면 현재 HP는 새 상한으로 잘린다. MaxHp가 늘어도 현재 HP는 안 채워진다.

## 2. 연결법 (Unity)

1. 플레이어(`PlayerAgent` 있는 오브젝트) 선택
2. Add Component → `PlayerStatsModule`
3. 프리팹이면 Apply
4. 숫자는 이 컴포넌트만 수정. `PlayerHealth` / `PlayerMover`의 속도·MaxHp는 폴백이라 모듈이 있으면 무시됨
5. Inspector 기본값은 플레이 시작 때 한 번만 읽음. 플레이 중 바꿔도 재시작해야 반영
6. 확인: 플레이 중 `PlayerStatsModule` 톱니바퀴 → **Log Stats**

안 붙이면 콘솔에 `PlayerStatsModule이 필요합니다`가 뜬다.

이미 연결돼 있는 곳 (KYR가 해둠):

- MaxHp, Defense, HealReceived → `PlayerHealth`
- Walk/Run/Crouch, JumpHeight, AirControl, Dash 배율 → `PlayerMover`
- Damage, WeakpointMultiplier → `PlayerAgent.ApplyDamageTo`
- AttackSpeed, ReloadSpeed → `PlayerWeapon` (HJH `StatusEffectModule` 배율과 곱함)
- RecoilControl → `PlayerWeapon.ApplyRecoil`
- SkillCooldownReduction → `SkillStateBase.IsReady` (Q/E/X 쿨)

아직 연결 안 된 것:

- MaxStamina / StaminaRegen — 트리에만 있음. 게이지·대시 소모는 없음
- 스킬 전용 데미지 — 트리에 없음. 스킬도 `ApplyDamageTo`면 Combat `Damage`가 곱해짐
- 무기 에셋의 기본 데미지/연사력 — 그대로 두고 배율만 곱함

피해를 줄 때는 반드시 `owner.ApplyDamageTo(...)` 를 쓸 것.
`target.TakeDamage`를 직접 치면 Damage 배율이 안 들어간다.

## 3. 사용법 (코드)

```csharp
using Members.KYR._01_Scripts.Stats;

PlayerStatsModule stats = player.Stats;
```

### 읽기

```csharp
float dmg = stats.Get(PlayerStatId.Damage);
float walk = stats.Get(PlayerStatId.WalkSpeed);
```

### 버프 붙이기 / 떼기

네 번째 인자 `duration`이 없으면 영구. `> 0`이면 그 초 뒤에 자동으로 빠진다.
중간에 끊을 때는 `RemoveModifiers(source)`.

```csharp
// 이동 전체 +10% (영구)
stats.AddModifier(
    PlayerStatId.Mobility,
    new StatModifier(this, StatModifierType.PercentAdd, 0.1f));

// MaxHp +20
stats.AddModifier(
    PlayerStatId.MaxHp,
    new StatModifier(this, StatModifierType.Flat, 20f));

// 공속 +20%
stats.AddModifier(
    PlayerStatId.AttackSpeed,
    new StatModifier(this, StatModifierType.PercentAdd, 0.2f));

// 스킬 쿨 20% 감소 (Defense와 같이 Flat, 0~1)
stats.AddModifier(
    PlayerStatId.SkillCooldownReduction,
    new StatModifier(this, StatModifierType.Flat, 0.2f));

// 이 스킬/버프가 준 것 전부 제거
stats.RemoveModifiers(this);
```

`Source`는 보통 `this` (스킬 데이터, 버프 모듈). 같은 source로 붙은 모디파이어가 한 번에 빠진다.

임시 버프 예:

```csharp
// 5초 동안 이동 +10%. 시간 끝나면 알아서 제거
stats.AddModifier(
    PlayerStatId.Mobility,
    new StatModifier(this, StatModifierType.PercentAdd, 0.1f, 5f));
```

### 모디파이어 종류

- `Flat` — 더하기 (`+20`)
- `PercentAdd` — 퍼센트 합산 후 곱 (`0.1` = +10%)

Defense / RecoilControl / SkillCooldownReduction은 0~1 감소율이다. Flat `0.2`면 20% 감소.
배율 스탯(Damage, AttackSpeed, HealReceived, DashSpeed 등)은 기본 1이다.

### HJH StatusEffectModule

별개 시스템이다. 공속/장전은 트리 값 × `BuffType` 값이 된다.
트리만 올리고 `StatusEffectModule`만 올리면 둘 다 들어간다. 중복으로 같은 버프를 양쪽에 넣지 말 것.

## 4. 파일

| 파일 | 역할 |
|---|---|
| `PlayerStatId` | 이름표 |
| `PlayerStatTree` | 나무 구조 |
| `StatNode` | 칸 하나 |
| `StatModifier` / `StatModifierType` | 버프 스티커 |
| `PlayerStatBases` | Inspector 기본값 묶음 |
| `PlayerStatsModule` | 플레이어에 붙이는 모듈 |
