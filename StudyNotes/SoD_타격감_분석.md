## 장면 A — 적에게 스킬(불꽃탄) 명중 (≈2.55~3.1s)

기준 프레임 0 = 명중 직전. (30fps)

| 프레임(ms) | 보이는 것 |
|---|---|
| 0~66 | 플레이어 발밑에 노란 원형 광(시전 플래시), 노란 빔이 적에게 날아감. 적 머리 위 작은 주황 "45"(이전 타격 숫자) + 빨간 HP바 |
| **100** | **명중 프레임.** 적 몸 전체가 노랗게/하얗게 타오름(전신 플래시), HP바가 빨강→노랑으로 순간 변색 |
| **133** | 하얀 스파이크형 폭발 + **"90" 크리티컬 숫자가 큼직하게 등장**(붉은 채움 + 흰 외곽선, 두꺼운 폰트). 옆에 작은 "62" 부가 숫자 |
| 133~200 | 큰 숫자 **3프레임(~100ms) 유지**, 폭발 광은 흰색→주황색으로 식어감. 적 위로 회색 연기 시작 |
| 233~267 | 숫자가 **약 60% 크기로 축소**하며 폭발 중심에서 위로 살짝 이동. 주황 방사선(충격파 선) |
| 300~500 | 숫자 작게 고정되어 떠 있음(페이드 없이 0.5s+ 유지), 불꽃 꼬리·불씨·연기 잔류. 적은 몸을 뒤로 젖힌 피격 포즈 |

핵심:
1. **전신 플래시 1~2프레임(33~66ms)** — 색은 스킬 속성색(노랑/주황). 빨강 아님.
2. **숫자 = 팝인(큼) → 100ms 유지 → 축소.** 크기 변화가 타격 임팩트를 만듦. 크리는 색·크기·폰트가 일반과 다름("45"는 작은 주황, "90"은 큰 빨강+외곽선).
3. 플래시 → 폭발(흰→주황 2단계 색) → 연기/불씨 순으로 **이펙트가 시간차로 이어짐** (1프레임 이펙트가 아님, 약 0.4s).
4. 적 위치가 크게 밀려나지 않음 — **넉백은 "몸을 젖히는 포즈"로 표현**, 이동 거리는 작다(확정 아님).

## 우리 프로젝트에 가져갈 후보 (다음 채팅용)

1. **숫자 연출 3단계**: 큰 팝인 → ~100ms 유지 → ~60%로 축소 후 0.5s 이상 유지. 일반/크리/받는 피해 색·크기 분리 (현재 `PlayerHitReaction` 빨간 숫자 하나뿐).
2. **전신 플래시를 속성색으로** (붉은색 고정 X), 1~2프레임.
3. **이펙트 시간차 레이어**: 플래시 → 폭발(흰→주황) → 연기/불씨 → 파편.
4. **플레이어 피격 오버레이: 즉시 on / 약 1s 페이드 off** 비대칭 (`PlayerDamageScreenFx`).
5. **히트스톱은 짧게(≤3프레임) 또는 강타에만** — 현재 heavy hit 히트스톱 값을 SoD 클립 기준으로는 줄이는 쪽이 안전.
6. 넉백은 이동 대신 **젖힘 포즈 위주**, 위치 이동은 작게.

| | 가운데 (전 → 피크) | 가장자리 (전 → 피크) | 지속 |
|---|---|---|---|
| **SoD** | 74,81,96 → 74,80,96 (**변화 없음**) | 40,48,71 → 70,37,60 (R +75%, G −23%) | 피크 ~0.15초, 꺼지는 데 ~0.8초, 총 ~1.0초 |

- SoD 클립은 HP가 91% 아래로 안 내려감 → **딸피 PP는 SoD에서 측정 못 함**
