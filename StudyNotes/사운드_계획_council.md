# 사운드 계획 — Council 결론 (2026-11-05)

- 검토: 사운드 디자이너 / Unity 오디오 프로그래머 / 소스·워크플로 담당 (Sonnet 3명) → 종합
- 근거: SoD 녹화 스펙트로그램·음량 측정, 우리 코드(`Char/Audio/`) 직접 읽음, 라이선스 웹 확인
- 원칙: **기준은 SoD** ([[feedback-sod-is-reference]]). SoD 소리는 **측정만**, 파일로 쓰거나 프로젝트에 넣지 않음
- 관련: [[SoD_타격감_분석]], [[Council_리뷰_2026-11-05]]

## 한 줄 결론

**"완성된 소리 하나를 고르는" 방식을 버리고, "재료(어택·바디·꼬리)를 조합하는" 방식으로 바꾼다.**
스킬 54개를 하나씩 만들지 말고, **재료 ~15개 + 조합 규칙**으로 대부분을 덮는다.

## 왜 지금 소리가 "안 어울렸나" (3명 의견 종합)

1. **한 겹짜리 소리.** SoD 명중음을 스펙트로그램으로 보면 3겹: 날카로운 클릭(전 대역) → 0.15초 저음 "쿵" → 0.2초 고음 지글거림 꼬리. 팩에서 잘라온 소리는 이 중 한 겹뿐 → 얇고 가벼움
2. **팩마다 질감이 다름.** Magic Spell / Hove / Kenney 를 섞어서 녹음 방식·잔향이 제각각 → 한 게임 소리처럼 안 들림
3. **음량 기준이 없음.** 클립마다 볼륨을 손으로 맞췄고, 코드상 볼륨은 최대 1(증폭 불가). 믹서·리미터 없음
   - ⚠ 측정한 우리 녹화(−34 LUFS, 첫 클립 무음)는 **공통 효과음이 꺼진 상태**라 실제 비교치가 아님 → 켜고 다시 측정 필요

## 소리 하나의 구조

| 단계 | 어택 (클릭, 0~30ms) | 바디 (저음 무게) | 스위트너 (원소 질감) | 꼬리 (여운) |
|---|---|---|---|---|
| 준비·차징 | – | 낮은 웅 (반복) | 올라가는 소리 | – |
| **시전** | 필수 | 필수 | 선택 | – |
| 날아감 | – | 얇게 (반복) | 원소 질감 | – |
| **명중** | 필수 | 필수 (~0.15초) | 필수 | 필수 (~0.2초) |
| 장판·지속 | – | 반복 | 질감 | – |

- 모든 스킬이 5단계일 필요 없음. **시전·명중만 필수**
- 단계 = 지금 코드의 `trigger + time` 으로 이미 됨. **레이어(같은 순간 여러 겹)와 변형(랜덤)은 코드 추가 필요** (아래)

## 원소 소리 팔레트 (재료 규칙)

| | 바디 | 스위트너 | 꼬리 |
|---|---|---|---|
| 총 (거너) | 짧은 저음 "탁" | 없음 (초당 8발 → 짧고 건조) | 거의 없음 |
| 관통탄 (10발째) | 총소리 + 저음 바디 | 고음 휙 | 짧게 |
| 불 | 저음 "퍼엉" 럼블 | 불꽃 지글 (SoD 명중음과 같은 계열) | 중간 |
| 바람 | 노이즈 "휘익" | 고음 슈웅 | 짧음 |
| 땅 | 저음 "쿵" + 돌 깨짐 | 자갈 튐 | 거의 없음 (건조) |
| 전기 | 전기 웅 + 저음 펀치 | 지직 스파크 | 짧은 전기 여운 |
| 물 | 둔탁한 "촤" | 물방울·기포 | 젖은 여운 |

**어택(클릭) 재료 3개, 꼬리 재료 3개는 모든 원소가 공유** → 통일감

## 결론: 할 일 순서

### 0단계 — 기준 다시 재기 (10분)
- `SfxBank.muted` 끈 상태로 10초 녹화 → 실제 음량 측정. 지금 소리가 "작아서" 별로였는지 "질감이" 별로였는지 구분

### 1단계 — 코드 (약 1.5~2일, 각 단계 끝에 귀로 확인)
| # | 작업 | 귀로 확인할 것 |
|---|---|---|
| 1 | AudioMixer (Master / Music / SFX-플레이어 / SFX-적 / UI) + 리미터 + 에셋별 `gainDb` (증폭 가능) | 평타·피격 음량이 SoD 수준인지 |
| 2 | 재생 통로 하나로 합치기 (지금 `Sfx` 와 `SkillSoundPlayer` 가 보이스 풀을 따로 씀) + 이벤트별 동시 재생 상한 (총 3, 명중 4, 장판 2) | 초당 8발에 소리가 안 뭉개지는지 |
| 3 | **히트스톱 버그 수정**: `SkillSoundPlayer` 의 지연·holdTime 이 게임 시간 기준이라 히트스톱 중 멈춤 → 실제 시간 기준으로 | 히트스톱 때 소리가 밀리지 않는지 |
| 4 | `SoundLayer` (클립 변형 여러 개 + dB 랜덤 + 피치 + 지연) 추가. **기존 필드는 그대로, 추가만** → 에셋 안 깨짐 | 명중음을 3겹으로 만들어 비교 |
| 5 | 반복 소리를 스킬 끝·명중 때 끄는 `stopOn` | 날아가는 소리가 남지 않는지 |

> 디자이너는 "같은 시간에 엔트리 3개 넣으면 레이어 된다"고 했지만, 프로그래머 지적대로 그러면 **랜덤 변형이 따로 놀아 짝이 안 맞음** → `SoundLayer` 로 묶는 게 맞음

### 2단계 — 재료 모으기
- **소스 우선순위**: ① Sonniss GDC 번들 (로열티 프리, 상업 가능, 표기 불필요, 전문 녹음 — 수 GB, **사용자가 직접 받기**) ② Freesound **CC0 만** (NC 금지) ③ Kenney (UI)
- 기존 Magic Spell 등은 "완성품"이 아니라 **재료로 강등**
- 조합·정규화는 Claude 가 ffmpeg 로 (레이어 오프셋, 피치, 필터, 음량)

### 3단계 — 만드는 순서 (빈도 높은 것부터)
1. **평타 총소리** (가장 많이 들림 → 거슬리면 게임 전체가 거슬림)
2. **명중 / 크리** (크리 = 같은 명중음 + 스위트너 한 겹)
3. **처치** (보상 신호 → 가장 기분 좋은 소리)
4. **플레이어 피격** (짧고 분명하게)
5. **대시** (재장전 신호이기도 함)
6. **대시 충격포 / 궁극기** (드물지만 무겁게)
7. 원소 5종 **공통** 시전·명중 (10개) → 스킬 34개 대부분 이걸로 커버
8. 스킬별 전용 소리는 맨 마지막, 필요한 것만

### 작업 방식 (Claude 는 못 듣고, 사용자가 들음)
1. 사용자: 용도 하나 지정 ("명중")
2. Claude: 후보 3개 조합·측정·정규화 → 게임 안에서 1/2/3 키로 듣게 배치 (`SfxAuditionKeys` 이미 있음)
3. 사용자: 듣고 번호 + 한 줄 ("둔함", "너무 김")
4. Claude: 반영 + `CREDITS.md` 기록
- 한 바퀴 5~7분, 용도당 1~2바퀴

## 음량 기준
- 전체 믹스: **−16 ~ −18 LUFS** (SoD −16 측정)
- 클립: 트루피크 −1 dBTP 이하로 정규화 후 `gainDb` 로 조정
- 위계: 총소리 −6 dB (자주 나니까), 처치·피니셔 +3 dB

## 듣는 사람 체크리스트
- 평타 10초 연속으로 쏴도 귀가 안 피곤한가
- 소리 켠 쪽이 끈 쪽보다 타격감이 확실히 좋은가
- 눈 감고 명중 / 크리 / 처치가 구분되는가
- 눈 감고 5원소가 구분되는가
- 갑자기 튀게 크거나 작은 소리가 없는가
