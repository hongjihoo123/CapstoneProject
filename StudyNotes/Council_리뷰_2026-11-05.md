## 한 줄 결론

**타격감 "구조"는 SoD를 따라갔지만, 화면의 "색·밝기"가 SoD와 정반대라서 타격감이 잘 안 보인다.**
가장 효과가 큰 한 수는 이펙트가 아니라 **맵을 어둡게(남색 밤) 만드는 것**.

   - 확인한 값: `_HJH_Map.unity` 안개색 `(0.62, 0.78, 0.72)` Exp2 0.008, 앰비언트 강도 `1.25`, Sun 비어 있음
2. **이펙트 언어 섞임.** 청록 글로우 빔·링 vs 불투명 빨강/주황 셀 폭발 덩어리. 폭발이 캐릭터·숫자를 가림 (3명)
3. **붉은 부채꼴 사거리 표시.** 빨강 = 위험이라 헷갈리고 시선을 뺏음 (3명)
4. **피격 붉은 화면이 SoD보다 어둡고 탁함.** 전체 색필터(`hitScreenTint` 0.3)가 화면을 어둡게 함 (2명)
5. **숫자 겹침** ("8 8 25 8") (2명)

## 할 일 (효과 큰 순서)

### A. 라이팅 (질문 1·2·3 동시에 좋아짐) — 며칠
- 안개색 → 남색 `(0.10, 0.16, 0.30)` 근처, 앰비언트 강도 1.25 → ~0.6, 앰비언트 남색 계열
- Directional Light 달빛(청보라, 약하게)
- 맵 씬이 실제로 쓰는 Volume 확인 후 Bloom(threshold 1, intensity ~1), Color Adjustments(노출 -0.3, 채도 +15)
- ⚠ 맵은 공유 에셋 → 씬 백업 먼저 (메모리 규칙)

### B. 타격감 미세조정 (오늘 코드) — 1시간
- `PlayerDamageScreenFx`: `hitScreenTint` 0.3 → 0.12, `hitVignette` 0.4 → 0.55, `hitHoldTime` 0.2 → 0.1 (가장자리 위주로 붉게)
- `CombatFeedback`: 같은 대상에 0.1초 안에 연속으로 뜨는 숫자는 위로 +0.25씩 쌓기 (지금 ±0.3 랜덤 옆 퍼짐만 있음)
- 크리 숫자 축소가 프레임에서 잘 안 보임 → `peakScale.y` 1.7 → 2.0 또는 `popHoldTime` 확인

### C. 이펙트 팔레트 규칙 — 며칠
- 배경(남색)과 안 겹치게 FX는 주황·노랑 + 마젠타 포인트, 청록은 환경 광원 전용
- 셀 폭발: 크기 ~0.6배, 수명 ~0.25초, 알파 페이드 + 중심 하이라이트 (흰→주황 2단계, SoD처럼)
- 사거리 표시: 빨강 → 거너 주색(흰/청록 or 앰버)으로 얇게, 평소엔 끄기

### D. 거너 키트 — 1주
- 대시 2개 겹침: 질주(쿨 3, 2충전)와 대쉬 충격포(쿨 3) → 충격포 쿨 5~6초로 나누거나 질주 강화형으로 합치기
- ~~Q/E 중 하나를 거너 전용 스킬로~~ → **보류.** 검토자가 원소 스킬을 `Swap_Fire` 1개만 보고 판단함. 실제로는 원소 스킬 34개(불·바람·땅·전기 7개, 물 6개) + 피니셔 5 + 체인 4 + 스왑 5. 재검토 필요
- 거너 림라이트/외곽선으로 가독성

### D-2. 거너 재검토 (스킬 전체 기준, 두 번째 녹화 `192322.mp4` 반영)

- 판정 그대로 **손볼 곳 많다 (다시 짤 정도는 아님)**. "Q/E를 거너 전용으로" 조언은 **철회**: Q/E는 원소 스왑 슬롯이고, 콤보·피니셔로 가는 입력 길이라 고정하면 콤보 시스템이 죽음
- 구조 (코드 확인): Space/RMB/R = 거너 키트(각각 바람/전기/불 원소 달림), Q/E = 주운 원소 스킬. 원소 스킬 쓸 때마다 5초 체인 → 콤보(스택 최대 3) → 원소 3개 조합이면 피니셔 저장 → C로 소모하면 다음 스킬 ×1.3/1.6/2.0 + 피니셔
- 밸런스 이상치 (값 직접 확인한 것 ✔):
  - ✔ 권총 8뎀 × 초당 8발, 탄창 12, 장전 1초 → **지속 DPS ≈ 38** (검토자는 64라 했지만 장전 빼먹음). 그래도 쿨 스킬 최고(~20)의 2배 → 스킬 쓸 이유가 약함
  - ✔ Fire_Fireball 쿨 1.5 / 30뎀 (DPS 20, 가장 효율 좋음), Electric_Thunderbolt 쿨 2.5 / 40뎀
  - ✔ Gunner_ShockCannon 쿨 20 / 120뎀 → 궁극기가 Boulder(쿨 3/40) 연타보다 약함
  - Gunner_DashBlast 쿨 3 / 25뎀 → 거너 고유 스킬이 주운 스킬보다 약함
  - Swap 계열 쿨 편차 큼 (Wind 1.5초 2충전 vs Earth 7초)
- 개선 후보: ① 권총 `damagePerShot` 8 → 6~7 또는 Fireball 30→24 / Thunderbolt 40→34 ② DashBlast 25→40, ShockCannon 쿨 20→14 + 120→150 ③ **패시브 ChargedShot(10발마다 관통탄)이 마지막에 쓴 원소를 따라가게** (불=화상, 전기=체인) → 총과 원소 콤보가 연결되는 가장 싼 방법
- 확인 못 함: 적 체력(→ 실제 몇 대에 죽는지), JJH 콤보표 수치, 지속 피해형 스킬 합산
