# 건파이어 리본(Gunfire Reborn) vs 우리 게임 — 기획·타격감 비교

- 작성: 2026-11-05. 근거 = 웹 검색 (가이드·리뷰·패치노트) + Claude 사전 지식
- **⚠ 개발자 인터뷰·GDC 같은 "타격감을 이렇게 만들었다" 공식 자료는 못 찾음.** 아래 [확인됨] = 출처 있음, [기억] = Claude가 알고 있는 내용 (직접 플레이 영상으로 확인 필요)
- 관련: [[SoD_타격감_분석]], [[Council_리뷰_2026-11-05]]

## 1. 기획이 겹치는 부분

| 요소 | 건파이어 리본 | 우리 게임 | 차이 |
|---|---|---|---|
| 장르 | 1인칭 FPS 로그라이트 | 탑다운 TPS 로그라이트 | **카메라가 다름 → 타격감 기법이 많이 갈림** |
| 영웅 | 영웅마다 고유 스킬 + 보조 스킬 + 패시브 [기억] | 캐릭터 교체, 거너 = 대시/우클릭/궁 + 패시브 | 비슷 |
| 원소 | 불(화상)·번개(감전)·부식 3종 상태이상 [확인됨] | 원소 5종(불·바람·땅·전기·물) 스킬 34개 | 우리는 원소가 "스킬", 건파는 원소가 "탄에 붙는 상태" |
| 원소 조합 | 상태 2개가 겹치면 융합 발동. 화상+부식 = 독기(Miasma, 초당 최대체력 12% × 5초), 연소(Combustion) = 주변 적 경직 + 피해 200% [확인됨]. 일부 융합은 보스에 안 통함 [확인됨] | 원소 스킬 연속 사용 → 콤보 → 3원소 피니셔 | **구조가 거의 같음.** 건파는 "적에게 쌓인 상태"로 조합, 우리는 "내가 쓴 스킬 순서"로 조합 |
| 적 방어 층 | 체력(빨강) 위에 방어구(노랑)·보호막(파랑) 바. 원소마다 잘 먹히는 층이 다름 (예: 번개 → 보호막) [기억] | 체력 1층 | 우리에게 없는 축 |
| 약점 | 머리 등 약점 → 치명타. 정확도로 결정 [확인됨] | `IsWeakpoint` 있음 (크리 숫자) | 탑다운이라 "조준해서 약점" 맞추기 어려움 |
| 빌드 | 두루마리(스크롤) + 레벨업 때 고르는 각성(Ascension), 보너스 수치가 크게 큼 [확인됨] | 원소 스킬 줍기/교체, 보상 흐름은 아직 약함 | 건파는 "고를 때마다 확 세짐"이 핵심 재미 |

## 2. 타격감·이펙트 — 어떻게 했나

### [확인됨] 출처 있는 것
- **소리가 손맛의 큰 부분.** 리뷰들이 사격이 "snappy(찰짐)", 소리가 크게 기여한다고 평가 (GameGeeker, Quarter to Three)
- **상태이상을 HUD 에도 표시.** 2020 패치에서 주요 상태 피드백을 상태 바에 추가. 감전은 적에게 걸면 내 화면 하단에도 뜸
- **원소 이펙트 버그 수정 기록** (연쇄 번개 이펙트, 공격 후 남는 이펙트) → 원소 이펙트를 꽤 많이 써서 정리가 필요했던 게임
- **약점: 플레이어 불만도 있음.** "맞았을 때 피드백이 부족해서 경고 없이 죽는다" (RAWG 유저 리뷰) → 건파도 **플레이어 피격** 쪽은 약하다는 평

### [기억] 확인 필요 — 녹화로 프레임 분석하면 확정 가능
- 크리(약점) 숫자는 색·크기가 일반과 다름 + 전용 "딩" 소리
- 크로스헤어 히트마커 (맞으면 조준점이 잠깐 바뀜, 처치 시 다른 모양)
- 적 체력바 위 층(보호막/방어구)이 깨질 때 전용 이펙트·소리
- 원소 상태가 걸리면 적 머리 위 아이콘 + 몸에 색 이펙트 (불=주황 불꽃, 번개=파란 전기, 부식=초록)
- 적 경직은 피해량·무기에 따라, 큰 적은 거의 안 밀림
- 밝고 채도 높은 카툰 셀 스타일 (SoD 의 어두운 밤과 정반대 → 우리 맵 밝기와 오히려 가까움)

## 3. 우리에게 가져올 만한 것

> **원칙 (2026-11-05 결정): 연출·타격감·비주얼의 기준은 SoD.** 건파이어 리본은 기획 구조가 겹쳐서 *비교용*으로만 봄.
> 건파 고유 연출(적 머리 위 원소 아이콘 등)은 SoD 방향과 안 맞으면 가져오지 않음.

| 순위 | 아이디어 | 이유 | 비용 |
|---|---|---|---|
| ~~1~~ | ~~원소 상태 아이콘을 적 머리 위에~~ → **안 함.** SoD 에 없는 연출이고, 우리는 SoD 를 따라감 | — | — |
| 2 | **원소별 피격 이펙트 색 고정** (불=주황, 전기=노랑/보라, 물=파랑…) | 이미 `HitTint` 로 원소색 번쩍임은 있음. 숫자·불꽃까지 원소색 규칙을 문서로 고정 | 작음 |
| 3 | **크리/약점 전용 소리** | 건파·SoD 둘 다 "크리는 소리로도 다르다" | 작음 (Sfx.Bank 에 슬롯 추가) |
| 4 | 적 방어 층 (보호막/방어구) + 원소 상성 | 원소 5종이 "어디에 써야 좋은지"가 생김 → 빌드 선택 이유 | 큼 (적 = JJH 담당, 팀 합의 필요) |
| 5 | 플레이어 피격 피드백은 건파 말고 SoD 를 따라갈 것 | 건파는 이 부분이 약하다는 평이 있음 | — (이미 함) |

**가져오면 안 되는 것:** 크로스헤어 히트마커·총 반동·1인칭 화면 흔들림 같은 FPS 전용 기법. 탑다운에선 의미가 다름.

## 4. 더 정확히 하려면
SoD 때처럼 건파이어 리본을 10~20초씩 녹화하면 프레임 단위로 확정 가능:
1. 제자리에서 일반 적 몸통 쏘기 → 머리(약점) 쏘기
2. 보호막/방어구 있는 적의 바 깨기
3. 원소 2개 걸어서 융합 터뜨리기
4. 일부러 맞기 (플레이어 피격)
