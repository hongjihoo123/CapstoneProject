## 우리 코드 지도 (폴더별 한 줄)

```
02.Scripts/
├─ Char/FSM_Skill_Module/   스킬 시스템 본체. "키 → 스킬 실행 → 쿨다운"          → 03장
│   ├─ Chain/ Gunner/ RuneMage/ Player_1/   캐릭터별 스킬 데이터
│   └─ Effects/             투사체·지연폭발 (스킬이 끝나도 살아있는 것)
├─ SkillSwap/               바닥에 놓인 스킬과 내 스킬 바꾸기                     → 05장
├─ Element/                 원소 콤보 판정 + 원소 색 팔레트                         → 06장
├─ Hud/                     로직과 UI 사이의 "창구" (PlayerHudSource, ComboKeyMap) → 04장
├─ UI/                      화면에 보이는 것들 (스킬바, 콤보 연출, 커서...)          → 04, 07장
├─ Char/Visual/             이펙트·타격감 (Fx, HitFeel)                            → 07장
└─ Char/TopDown/            탑다운 카메라, 마우스 조준
```

## 큰 흐름 4개 (이것만 머리에 넣으면 나머지가 붙는다)

```
① 스킬 사용     키보드 → PlayerAgent → SkillStateModule → GenericSkillState → SkillData.Begin → 실행 객체
② 콤보          SkillStateModule.SkillUsed ─▶ ElementComboChain(판정) ─▶ ComboLanded 이벤트 ─▶ UI 연출
③ 스킬 교체     F키 → SkillSwapInteractor → (Q/E 가로채기) → SkillPickup.Swap → SkillStateModule.Equip
④ 화면 표시     로직들의 이벤트 ─▶ PlayerHudSource(창구) ─▶ UI 스크립트들
```

화살표 방향을 기억하세요: **로직은 UI를 모른다. UI만 로직(창구)을 안다.**
